# Diplom_3
## О проекте

Данный проект представляет собой автоматизированные тесты для веб-приложения, использующие Selenium WebDriver, JUnit, RestAssured и Allure для создания, выполнения тестов и формирования отчетов. Проект включает в себя тестирование различных функций приложения, таких как регистрация, авторизация, страница профиля и конструктор.

Проект организован следующим образом:

api — пакет, отвечающий за создание тестового пользователя через API.
models — содержит модели для создания объектов тестовых пользователей (например, класс User).
pageobjects — пакет с классами Page Object, отвечающими за взаимодействие с элементами страницы.
utils — содержит утилиты для генерации рандомных пользователей.
webdriver — класс для настройки и управления WebDriver, с поддержкой переключения между браузерами (например, Google Chrome или Yandex).

## Запуск тестов

Для запуска тестов используется Maven и JUnit. Вы можете указать браузер, который будет использоваться при тестировании, через параметр -Dbrowser.

Запуск с использованием Google Chrome:
mvn test -Dbrowser=chrome
Запуск с использованием Yandex Browser:
mvn test -Dbrowser=yandex
